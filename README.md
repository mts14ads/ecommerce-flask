# Plataforma de E-commerce - CRUD Flask

Projeto acadêmico desenvolvido com Python, Flask, Flask-SQLAlchemy e SQLite.

## CRUDs implementados

- Usuário
- Categoria
- Anúncio
- Pergunta
- Compra
- Lista de Favoritos
- Favorito

Todas as entidades possuem operações de cadastro, consulta, edição e exclusão.
As exclusões possuem confirmação no navegador.

## Execução

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Acesse http://127.0.0.1:5000/
